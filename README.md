# Sundae
Sundae is a hard fork of Butterscotch with the primary aim of adding support for more games.

## Platform support
I aim to maintain support with as much platforms as realistically possible that i can test, and even adding more.
However, i will not be maintaining support for old/limited compilers like TinyCC, GCC 2.4 and more.
Compiler support:
* GCC
* Clang
* MSVC
Supported platforms
* macOS
Untested platforms
* Linux
* Windows
* Haiku
* Switch
* Web
* PS2
* etc etc

## Additions
* Video playback, fixing DELTARUNE Chapter 3 and 5.
* Fullscreen support
